F1 Demo — paso a paso

Todo lo que tocas y dices, en orden. Pensado para no perderte y que se vea fluido.

🔒
Uso interno: URLs de login, usuario y clave del esquema están en el README.md de esta carpeta / CONEXION-OCI.md. No proyectar credenciales.

0 Antes de empezar (5 min antes)

  1. Encender la base
    bash oci-ambiente/adb-control.sh start — espera a AVAILABLE (~1 min).
  2. Abrir dos pestañas
    (1) el dashboard (artefacto) y (2) Database Actions (…/ords/sql-developer, login como F1DEMO).
  3. Calentar SELECT AI
    Corre una pregunta de prueba para que el primer llamado no salga lento en vivo.

1 El gancho — el dashboard (≈4 min)

  1. Abrir el dashboard
    Muestra KPIs, clasificación animada y la evolución de puntos. Deja que "respire" 3 segundos.
    🗣️: "Esto son datos de una temporada de F1. Miren el tablero — pero lo interesante no es el tablero, es cómo le preguntamos."
  2. Jugar con SELECT AI (en el dashboard)
    Toca las preguntas en español. Muestra que aparece el SQL que la base escribió sola + el resultado.
    🗣️: "No escribí SQL. Le pregunté en español y la base entendió mis tablas y armó la consulta. Esto se llama SELECT AI y vive dentro de la Autonomous Database."

2 El "de verdad" — SELECT AI en la base real (≈6 min)

Pasa a Database Actions (F1DEMO) y corre esto en vivo. Copia y pega:

  1. Ver el SQL que escribe la IA
    select dbms_cloud_ai.generate(
  prompt => 'quien lidera el campeonato',
  profile_name => 'F1_AI', action => 'showsql') as sql_de_la_ia
from dual;
    🗣️: "Le pido en español y me muestra el SQL — con su JOIN y su subconsulta. La IA conoce mi modelo de datos."
  2. Que además lo ejecute
    select dbms_cloud_ai.generate(
  prompt => 'top 3 escuderias con mas puntos sumando sus pilotos',
  profile_name => 'F1_AI', action => 'runsql') as resultado
from dual;
    Devuelve: McLaren 512 · Red Bull 441 · Ferrari 438.
  3. Improvisar con la audiencia
    Pide una pregunta a la sala y escríbela en el prompt. Ideas seguras:
    Prueba: "cuantas victorias tiene cada piloto de Ferrari" · "pilotos espanoles ordenados por puntos" · "cuantos pilotos hay por escuderia"
    🗣️: "Pregúntenme algo ustedes. Lo escribo tal cual y la base responde."

3 El cierre — el mensaje (≈3 min)

  1. Volver al dashboard y rematar
    🗣️ Frase madre: "Esto no es un proyecto de meses. Tomamos datos, y en una tarde hay IA que responde en español y un tablero — todo dentro de Oracle Cloud, seguro, sin mover el dato a ninguna IA pública. Fácil, seguro e intuitivo."
  2. Conectar con Team One
    Si ya presentaron su caso F1: "Ustedes vieron el caso; esto es lo fácil que es montarlo sobre Oracle Cloud."

? Respuestas rápidas (Q&A)

¿La IA ve nuestros datos?Corre dentro de tu tenant; el dato no sale a una IA pública. La identidad la da OCI (resource principal), sin claves.
¿Qué modelo usa?OCI Generative AI (aquí Llama 3.3 70B). Se puede cambiar de modelo sin tocar la app.
¿Sirve para otras bases?Es nativo de la Autonomous Database. Apuntas SELECT AI a tus tablas y listo.
¿Cuánto costó montar esto?Una tarde. Esquema aislado, datos de ejemplo, perfil de IA — sin infraestructura nueva.
